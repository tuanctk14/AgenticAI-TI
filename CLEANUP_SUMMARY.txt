1. CONSOLIDATION STRATEGY
   Decision: Merge by abstraction level, not function grouping
   Rationale: Preserves clean interfaces, enables easy future migration

2. REPOSITORY PATTERN
   Decision: Keep single abstraction, multiple concrete implementations
   Rationale: Enables Neo4j and SQLite coexistence, clean testing

3. AGENT TRANSPARENCY
   Decision: Internal consolidation doesn't require agent code changes
   Rationale: Agents use tool interfaces, not internal implementations

4. DATA STORAGE
   Decision: Move CWE mappings to JSON instead of Python dicts
   Rationale: Easier to update, reduces code LOC, better separation
